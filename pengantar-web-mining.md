# Pengantar Web Mining

## Pengertian Web Mining

Web Mining merupakan proses penerapan teknik data mining untuk menemukan informasi, pola, dan pengetahuan yang bermanfaat dari data yang terdapat di World Wide Web.

Data yang terdapat pada web memiliki berbagai bentuk, seperti teks, gambar, hyperlink, dokumen, dan data aktivitas pengguna.

Dengan Web Mining, data yang awalnya tidak terstruktur dapat dikumpulkan dan diolah sehingga menghasilkan informasi yang dapat digunakan untuk berbagai kebutuhan.

## Tujuan Web Mining

Beberapa tujuan Web Mining antara lain:

- Mengumpulkan informasi dari website.
- Menemukan pola dari data web.
- Mengekstraksi informasi yang relevan.
- Mengubah data web menjadi dataset yang dapat dianalisis.
- Mendukung proses pengambilan keputusan.

## Jenis-Jenis Web Mining

Secara umum Web Mining dapat dibagi menjadi tiga jenis.

### 1. Web Content Mining

Web Content Mining merupakan proses memperoleh informasi dari isi atau konten sebuah halaman web.

Contohnya adalah mengambil teks berita dari website berita.

### 2. Web Structure Mining

Web Structure Mining merupakan proses menganalisis struktur hubungan antarhalaman web melalui hyperlink.

### 3. Web Usage Mining

Web Usage Mining merupakan proses menganalisis pola penggunaan website berdasarkan aktivitas pengguna.

## Web Crawling

Web Crawling merupakan proses mengunjungi halaman web secara otomatis untuk mengambil informasi yang dibutuhkan.

Dalam project ini, Web Crawling digunakan untuk mengumpulkan berita dari website Detik.

Teknologi yang digunakan antara lain:

- Python
- Requests
- BeautifulSoup
- Trafilatura
- Pandas
- Jupyter Notebook
